# StreetQuest V21 — mise en ligne GitHub Pages

1. Décompresse le ZIP et copie **tout le contenu** à la racine de ton dépôt GitHub Pages.
2. Remplace les anciens `game.js`, `style.css`, `index.html`, `sw.js`, `manifest.json`, `version.json` et le dossier `server/`.
3. Commit puis push.
4. Attends la fin du déploiement GitHub Pages.
5. Sur iPhone, ouvre le jeu. Si l’ancienne PWA est encore affichée, ouvre **Menu > Réglages > Vérifier les mises à jour** puis recharge.

V21 utilise un nouveau cache `streetquest3d-v21` et une sauvegarde `sq3d-v21`. La partie V20.1 est migrée automatiquement.

Avant publication, utilise `V21_CHECKLIST.md`.
