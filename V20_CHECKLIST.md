# StreetQuest V20 — checklist de validation

## Monde
- [ ] Aucun lampadaire dans la chaussée.
- [ ] Tous les lampadaires sont des globes symétriques.
- [ ] Les feux sont à droite de chaque approche et leur face regarde le trafic concerné.
- [ ] Les passages piétons et lignes d'arrêt restent dégagés.
- [ ] Les portes d'immeuble mènent vers un trottoir ou une ruelle.
- [ ] Aucun bâtiment ne coupe un corridor d'entrée.
- [ ] Le centre paraît dense dès le chunk de départ.

## PNJ
- [ ] Pas de PNJ coincé durablement dans un mur.
- [ ] Les PNJ récupèrent un waypoint s'ils restent bloqués.
- [ ] Le soir il y a moins de monde que le jour.
- [ ] Dans un commerce, le vendeur regarde le comptoir / le client.
- [ ] Les clients décoratifs regardent le comptoir.

## Circulation
- [ ] +Z : voie ouest ; -Z : voie est.
- [ ] +X : voie sud ; -X : voie nord.
- [ ] Les voitures s'arrêtent au rouge / jaune.
- [ ] Phase tout rouge présente.
- [ ] Pas de fusion volontaire de voitures dans le carrefour.

## Mobile / GitHub Pages
- [ ] Pas de zoom/pinch Safari.
- [ ] Joysticks utilisables avec un doigt chacun.
- [ ] Mini-carte lisible.
- [ ] Service worker charge `streetquest3d-v20`.
- [ ] `version.json` affiche 20.0.
- [ ] Sauvegarde V19 migrée sans perdre la progression.
